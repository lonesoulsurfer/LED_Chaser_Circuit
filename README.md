# LED Chaser

This is a classic "Knight Rider" LED chaser. The LEDs light one after the other, from left to right and back. A light-dependent resistor (LDR) controls the speed: when it is darker, the LEDs move more slowly.

![LED Chaser](https://github.com/user-attachments/assets/e0fbc303-bd00-4fd0-96e0-9704274bb7ea)

I made it to add some life to a small Junkbot, made from an old shaver and an umbrella.
